************************
Lablink datapoint bridge
************************

.. meta::
   :description lang=en: Lablink datapoint bridge

This package provides the Lablink datapoint bridge.
The bridge is a Lablink client that connects datapoints of other clients.
It subscribes to each datapoint named in its configuration.
When a source datapoint receives a new value, the bridge writes that value to the destination datapoint.
The source and the destination must have the same datatype, and each connection is one-way.

The configuration is a JSON document.
It can be supplied as that JSON directly, or generated by a Python script.
See :doc:`configuration` for both forms.
